# Patient Appointment No-Show Prediction

## Project Summary

This project applies machine learning techniques to predict whether patients will miss scheduled medical appointments using real-world healthcare appointment data. The analysis focuses on identifying the strongest predictors of no-show behavior and evaluating predictive models that can support healthcare scheduling and operational decision-making.

---

## Project Objectives

* Predict whether a patient will attend or miss a scheduled appointment
* Identify the key factors contributing to no-show behavior
* Compare multiple machine learning models
* Generate actionable insights from healthcare scheduling data

---

## Dataset Information

### Source

Kaggle – Patient Appointment No-Show Prediction Dataset

### Description

The dataset contains over 100,000 healthcare appointment records and includes:

* Patient demographic information
* Scheduling details
* SMS reminder information
* Previous no-show behavior
* Appointment timing variables
